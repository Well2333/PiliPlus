# 增加 VideoTogether 兼容的一起看房间

## 做了什么

- 调研上游、公开 fork、VideoTogether 官方客户端和服务端协议；
- 增加创建/加入房间、主客端播放同步、自动打开视频、缓冲等待、断线重连和文字消息；
- 在“我的”页增加入口，在设置中增加独立的 VideoTogether 子项；
- 增加双向“最后本地操作者接管”，修正房间更新确认匹配和初始时钟偏移；
- 增加可关闭双向接管的官方兼容模式：普通成员只跟随，创建者被接管后可自动降级并重新抢回控制权；
- 将播放中进度校正阈值默认值改为 0.5 秒，暂停和缓冲等待固定使用 0.1 秒精确校正；
- 对齐官方成员缓冲等待语义，并在等待状态变化时立即处理；跟随端同步忙碌时合并最新广播，避免丢状态；
- 在播放器三点菜单首项增加“一起看”，并可在 VideoTogether 设置中隐藏；
- fork Android CI 包使用 `.dev.ci`、Release 包使用 `.dev`，两者使用同一套固定开发证书；
- 增加协议纯逻辑测试、公共服务器双客户端冒烟验证和真机待测报告。
